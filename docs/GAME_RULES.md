# Game rules

Rules are selected by the room's game kind:

- [Dice5 rules](./games/dice5-rules.md) — the existing game.
- [Bet-a-lot rules](./games/betalot-rules.md) — the heads-up game.
- [Dice Blackjack rules](./games/blackjack-rules.md) — heads-up race to 21, with doubling twelve-sided overtime; also a bonus after every ten Bet-a-lot rounds.
- [Hit List slots](./games/hit-list-slots.md) — two earned Bet-a-lot tickets per session, five lockable reels, five spins, and live chip prizes; also available in free practice.
